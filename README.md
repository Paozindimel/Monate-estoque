
# Monate Estoque

Sistema de gerenciamento de estoque de produtos.

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Bootstrap
- Lombok
- Docker

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Edição de produtos
- Exclusão de produtos
- Painel com indicadores de estoque
- Status automático dos produtos
